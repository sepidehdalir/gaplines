# GapLines: Scene Rehearsal

A native rehearsal room for recorded dialogue and timed reply gaps.

**Status: in active production. Not submitted or released.**

An actor records partner dialogue, labels each segment and places editable silence for their own replies. Playback, scene ordering, portable backups and playable WAV audio export form one focused workflow.

Built for iPhone and iPad with SwiftUI, AVFoundation and StoreKit2. The iOS15 deployment target is maintained with the current SDK. Commercial source is private. This repository holds only the professional showcase and public support/privacy pages.

Engineering: immutable recorded takes, atomic scene manifests, monotonic pause/resume timing, guarded audio callbacks, fully validated staged restore, real-sample WAV rendering and one-time verified StoreKit entitlements. Verification limits and final visuals will be published after QA. No AI voices, transcription, account, cloud backend or learning guarantees.

Free: one full scene, single-scene audio export and backup/restore. Lifetime Pro: multiple scenes, saved gap presets and batch export. No subscription.
